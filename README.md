# Astrosheep-zero Tap

## How do I install these formulae?

`brew install astrosheep-zero/tap/<formula>`

Or `brew tap astrosheep-zero/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "astrosheep-zero/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
